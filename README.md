# ✍️ Tekenin.my.id - Buat Tanda Tangan Online PNG Transparan

> Web App 100% Client-Side untuk membuat tanda tangan digital dan menghapus latar belakang foto tanda tangan kertas menjadi format PNG transparan secara instan, gratis, dan aman.

Website: **[https://tekenin.my.id](https://tekenin.my.id)**

## ✨ Fitur Utama
1. **Gambar di Layar (Touchscreen & Mouse)**
   - Retina High-DPI Canvas (garis halus, tidak pecah).
   - Pilihan warna resmi: Hitam Pekat, Biru Dokumen Resmi (`#0026a3`), Merah Koreksi, dan Custom Color.
   - Pilihan tebal garis (Halus, Standar Pulpen, Spidol).
   - Fitur Undo, Clear, dan Auto-Crop pangkas area kosong otomatis.
2. **Scan Foto Kertas (Background Remover Otomatis)**
   - Unggah foto tanda tangan di atas kertas dari galeri atau kamera HP.
   - Slider *Threshold* untuk membersihkan bayangan kertas dan mengubahnya menjadi bening.
   - Pilihan warna tinta: Warna Asli, Hitam Solid, atau Biru Resmi.
3. **Ekspor & Salin Instan**
   - Unduh PNG Transparan Full HD.
   - Tombol 1-klik "Salin ke Clipboard" untuk langsung *Paste* (Ctrl+V) ke Microsoft Word / Google Docs.
   - Unduh JPG latar putih.
4. **100% Client-Side & Privasi Aman**
   - Seluruh pemrosesan dilakukan di peramban pengguna.
   - Tidak ada gambar atau data pribadi yang dikirim ke server.

## 🚀 Deployment
Web app ini siap di-deploy langsung ke **Vercel** atau **Cloudflare Pages** tanpa biaya server.
